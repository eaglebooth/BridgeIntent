## Scope and limitations

These live runs verify SDK signing, historical deployment/source parity at initial deployment time, submitter-scoped intent creation, unauthorized-binder rollback, duplicate-ID rollback, independent same-ID submitter namespaces, fail-closed handling of unavailable receipts, nonce replay rollback, independent assessments, and finalized state readback. They do **not** exercise semantic `MATCH` or `DIVERGED` using real receipt pairs on GenLayer. Do not present the placeholder hashes as real evidence. Current local schema v2 accepts public receipt pairs with a submitter distinct from the depositor; Direct Mode tests cover that boundary and current-ABI `MATCH`/`DIVERGED`. The updated source still must be deployed before the public Across example can be assessed live.

The JSON companion records all transaction hashes, receipts, readbacks, and the evidence-collector reconciliation note: [`studionet-20261020024950.json`](./studionet-20261020024950.json).
